- Projects
- About

## Important
The company's specific industry has not yet been confirmed.
This version intentionally uses general business content and avoids unverified claims about services, clients, pricing, certifications or locations.

Forms are static and need a backend or email integration.

## GitHub Pages
Upload the unpacked files to the root of `zamvestim.github.io`.
Then go to Settings → Pages → Deploy from branch → `main` → `/(root)` → Save.
